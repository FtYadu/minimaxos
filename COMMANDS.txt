-----------------------

STEP 3: Deploy to Netlify
--------------------------
Go to: https://app.netlify.com
• Click: "Add new site" → "Import an existing project"
• Choose: "GitHub"
• Select: "minimax-studio"
• Click: "Deploy site"

⏱️  Wait 2-3 minutes → ✅ LIVE!

❌ "Authentication failed"
---------------------------
# Option A: Use GitHub Personal Access Token
1. Go to: https://github.com/settings/tokens
2. Generate new token (classic)
3. Select: repo (full access)
4. Copy token
5. Use as password when pushing

# Option B: SSH Keys
ssh-keygen -t ed25519 -C "your_email@example.com"
cat ~/.ssh/id_ed25519.pub
# Add to GitHub: https://github.com/settings/keys


❌ "Remote already exists"
---------------------------
git remote set-url origin https://github.com/YOUR_USERNAME/minimax-studio.git
git push -u origin main


❌ "Build failed on Netlify"
-----------------------------
• Check: Build command = npm run build
• Check: Publish directory = .next
• Check: Node version = 18
• Already configured in netlify.toml ✅
