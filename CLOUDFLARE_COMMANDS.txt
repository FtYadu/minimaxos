STEP 3: Deploy on Cloudflare
-----------------------------
Go to: https://dash.cloudflare.com

1. Navigate to "Workers & Pages" (sidebar)
2. Click "Create application" → "Pages" tab
3. Click "Connect to Git"
4. Authorize GitHub (if first time)
5. Select repository: "minimax-studio"
6. Build settings (auto-detected):
   ✓ Framework preset: Next.js
   ✓ Build command: npm run build
   ✓ Build output directory: .next
7. Click "Save and Deploy"

⏱️  Wait 2-3 minutes → ✅ LIVE!

│ 🆘 TROUBLESHOOTING                                                       │
└──────────────────────────────────────────────────────────────────────────┘

❌ "Wrangler not found"
------------------------
npm install -g wrangler


❌ "Authentication failed" (GitHub)
------------------------------------
# Use Personal Access Token
1. Go to: https://github.com/settings/tokens
2. Generate new token (classic)
3. Select: repo (full access)
4. Copy token
5. Use as password when git asks


❌ "Build failed on Cloudflare"
---------------------------------
• Framework preset MUST be: Next.js
• Build command: npm run build
• Output directory: .next
• Already configured in wrangler.toml ✅


❌ "Wrangler login not working"
--------------------------------
# Manual auth
wrangler login --browser=false
# Copy URL, open in browser, paste token back
