# MiniMax Studio - Feature Update Walkthrough

This update introduces significant improvements to stability, workflow, and data management.

## 1. Job Queue System

We've implemented a robust job queue system to handle generation tasks efficiently.

### How it works:
- **Queueing**: When you click "Generate", the task is added to a queue instead of blocking the UI.
- **Sequential Processing**: Tasks are processed one by one to avoid rate limits and browser overload.
- **Status Indicators**: You can see the status of your generation (Queued, Processing, Completed) in the UI.

### Usage:
1. Go to the **Video Panel**.
2. Configure your video generation settings.
3. Click **Generate**.
4. A "Queue Status" indicator will appear in the left panel.
5. You can continue using the app while the video generates in the background.

## 2. Data Persistence (Import/Export)

You can now backup and restore your entire generation history and settings.

### Usage:
1. Click the **Settings** (gear icon) button in the top header.
2. **Export**: Click "Export Data" to download a JSON file containing all your generations, templates, and settings.
3. **Import**: Click "Import Data" and select a previously exported JSON file to restore your data.
   - *Note: Importing will overwrite your current data.*

## 3. Prompt Library

Save your favorite prompts and reuse them later.

### Usage:
1. Go to the **Video Panel**.
2. Type a prompt in the text area.
3. Click the **Save** button (floppy disk icon) below the text area.
4. Enter a name for your template.
5. To load a saved prompt, click the **Load** button (book icon).
6. Select a template from the list to populate the prompt area.

## 4. Progressive Web App (PWA) Support

MiniMax Studio is now installable as a native-like app on your device.

### Usage:
- **Desktop (Chrome/Edge)**: Click the "Install" icon in the address bar.
- **Mobile (iOS/Android)**: Use "Add to Home Screen" from the browser menu.
- The app works offline (caches static assets) and provides a standalone experience.

## 5. Audio Visualization

Experience your generated music with a real-time audio visualizer.

### Usage:
1. Generate or load a music track in the **Music Panel**.
2. Play the track.
3. The visualizer will display a dynamic frequency bar chart synchronized with the audio.

## 6. Unified Queue System

We've extended the queue system to ALL generation types:
- **Video**: Sequential processing.
- **Music**: Background generation with visualization.
- **Image**: Batch generation support.
- **Text**: Chat interface with queue integration.
- **Code**: Sandbox generation with queue integration.

## 7. UI Refinements

We've added new ways to navigate and manage your content.

### History Panel
- **Filtering**: Filter generations by type (Video, Image, etc.) and status.
- **Sorting**: Sort by date (Newest/Oldest).
- **Search**: Real-time search by prompt content.
- **Management**: Delete or open past generations.

### Command Palette (Cmd+K)
- **Global Shortcut**: Press `Cmd+K` (or `Ctrl+K`) anywhere in the app.
- **Navigation**: Quickly switch between panels (Video, Image, History, Media Gallery, etc.).
- **Actions**: Toggle sidebar, open settings, and more.

## 8. Media Gallery

Manage all your assets in one place.

### Features:
- **Generated Assets**: View, preview, download, and delete all content generated by the AI.
- **Uploaded Assets**: Upload, store, and manage your own files (images, videos, audio) for use in generations.
- **Filtering**: Easily filter assets by type (Video, Image, Music, etc.).

## 9. Testing Infrastructure

We've added a comprehensive unit testing suite using Vitest.

### Running Tests:

```bash
npm run test
```
This runs tests for:
- `MinimaxClient` (API interactions)
- `AppStore` (State management and Queue logic)
